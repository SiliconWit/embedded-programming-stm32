A coin cell holds very little energy. A logger that keeps its processor running empties one in less than a day, and somebody must then travel to the site to change it. The same logger, with the same cell, can run for most of a year if it sleeps between readings. In this final lesson you build a data logger that is asleep for 99.9% of the time: it wakes once a minute, reads a sensor, stores the reading in a flash memory chip and sleeps again. You also meet what firmware needs before it leaves your bench: read protection, option bytes and a bootloader. #STM32 #LowPower #Production

## What We Are Building

<Card title="Battery-Powered Data Logger" icon="star">
A data logger powered by a CR2032 coin cell (3V, ~220 mAh). Between measurements the STM32 is in Stop mode, a sleep in which its clocks are off and its memory is kept. ## STM32 Low-Power Modes

<InArticleAd />


A battery's capacity is current multiplied by time: a 220 mAh cell gives 220 mA for one hour, or 1 mA for 220 hours. Awake, this logger draws about 15 mA, so the cell would last 220 / 15 = 15 hours. Months of life need almost no current for almost all the time. One reading takes 50 ms, so the logger can sleep for the other 59.95 seconds of each minute.

```text
  Current
  15 mA |  *         *         *
        |  *         *         *
        |  * awake   * awake   * awake
        |  * ~50ms   * ~50ms   * ~50ms
  14 uA +--+---------+---------+------> time
           |  sleep  |  sleep  |
           |  60 s   |  60 s   |
```

The STM32F103 has three low-power modes, like a house at night: lights off but awake (Sleep), asleep with the fridge on (Stop, RAM kept), or closed with only the alarm clock running (Standby). The deeper the sleep, the less current, the more the chip forgets and the longer it takes to wake.

### Mode Comparison

| Mode | Current (typical) | Wakeup Time | RAM Preserved | Peripherals | Wakeup Sources |
|------|-------------------|-------------|---------------|-------------|----------------|
| Sleep | ~2 mA | Immediate | Yes | All running | Any interrupt |
| Stop | ~14 uA | ~5 us | Yes | Stopped (RTC runs) | EXTI, RTC alarm |
| Standby | ~2 uA | ~50 us (reset) | No (lost) | All off (RTC optional) | WKUP pin, RTC, IWDG |

### Why Stop Mode

Sleep stops only the processor, and 2 mA empties the cell in under five days. Standby draws the least but loses the RAM, so the program starts again from reset at every wake. Stop is the middle choice:

- The RAM is kept. All variables and peripheral settings survive, and the program continues from the line after the `__WFI()` instruction.
- The RTC keeps running from its own 32.768 kHz crystal, so its alarm can wake the chip at an exact time.
- The chip wakes in microseconds.
- 14 uA is low enough for months on a CR2032.

### Power Budget Calculation

The average current is the charge used in one cycle divided by the length of the cycle. Charge is current multiplied by time, here in microamp-seconds (uAs).

```
Sleep current:      14 uA (Stop mode)
Active current:     ~15 mA for ~50 ms (sensor read + flash write)
Wakeup interval:    60 seconds

Average current = (14 uA * 59.95 s + 15 mA * 0.05 s) / 60 s
                = (839.3 uAs + 750 uAs) / 60 s
                = 1589.3 uAs / 60 s
                = ~26.5 uA average

CR2032 capacity:    220 mAh = 220,000 uAh
Battery life:       220,000 uAh / 26.5 uA = ~8,302 hours = ~11 months
```

The 60 seconds of sleep use 839 uAs and the 50 ms awake use 750 uAs, so the sleep current costs slightly more than the work. Real losses (the regulator's own current, flash chip leakage, the cell's self-discharge) reduce the 11 months, which is why the target is 6 months.

Measure rather than trust two of these numbers. At 72 MHz the awake current may be nearer 30 mA (then about 39 uA and 7.7 months). A CR2032's 220 mAh is rated at about 0.2 mA, and pulses of 15 to 30 mA make its voltage dip, more as it ages: put a 100 uF capacitor across it. The sector erase every 256 entries adds under 1 uA.

## RTC Configuration and Alarm Wakeup

<InArticleAd />


In Stop mode the main clocks are off and the timers do not count, yet something must measure the 60 seconds: the RTC, a 32-bit counter with its own 32.768 kHz LSE (low-speed external) crystal, which draws well under a microamp.

```text
  32.768 kHz     divide       counter      equal to
  crystal    --> by 32768 --> RTC CNT  --> alarm value
  (LSE)          = 1 Hz       +1 each s    RTC ALR ?
                                               |
                                               v yes
                 CPU continues   <--   EXTI line 17
                 after __WFI()         wakes the chip
```

A prescaler divides 32768 Hz down to 1 Hz, so the counter rises by one each second. When the counter equals the value in the alarm register, the RTC signals EXTI line 17. EXTI is the external interrupt controller, one of the few parts that can still wake the chip in Stop mode.

### RTC Initialization

The RTC is in the backup domain, a small part of the chip that is write-protected so that a program fault cannot spoil the time. The code must first unlock it (the `DBP` bit) and then enter a configuration mode (the `CNF` bit) before each change. The backup domain survives a reset while power stays, so a running RTC is left alone.

```c
void rtc_init(void) {
    /* Enable PWR and BKP clocks */
    RCC->APB1ENR |= RCC_APB1ENR_PWREN | RCC_APB1ENR_BKPEN;

    /* Enable access to backup domain */
    PWR->CR |= PWR_CR_DBP;

    /* Already running (a reset with power kept): keep its count */
    if (RCC->BDCR & RCC_BDCR_RTCEN) {
        RTC->CRL &= ~RTC_CRL_RSF;
        while (!(RTC->CRL & RTC_CRL_RSF));
        return;
    }

    /* Enable LSE; it can take a second or more to start, and on some
     * low-cost boards it never does */
    uint32_t prescaler = 32768 - 1;
    RCC->BDCR |= RCC_BDCR_LSEON;
    for (uint32_t t = 0; !(RCC->BDCR & RCC_BDCR_LSERDY); t++) {
        if (t > 20000000) break;         /* about 2 s at 72 MHz */
    }

    if (RCC->BDCR & RCC_BDCR_LSERDY) {
        RCC->BDCR |= RCC_BDCR_RTCSEL_0;  /* LSE */
    } else {
        /* No crystal: the internal ~40 kHz LSI keeps the logger running,
         * but it is only accurate to tens of percent */
        RCC->CSR |= RCC_CSR_LSION;
        while (!(RCC->CSR & RCC_CSR_LSIRDY));
        RCC->BDCR |= RCC_BDCR_RTCSEL_1;  /* LSI */
        prescaler = 40000 - 1;
    }
    RCC->BDCR |= RCC_BDCR_RTCEN;         /* Enable RTC */

    /* Wait for RTC synchronization */
    while (!(RTC->CRL & RTC_CRL_RSF));

    /* Enter configuration mode */
    while (!(RTC->CRL & RTC_CRL_RTOFF));
    RTC->CRL |= RTC_CRL_CNF;

    /* Set prescaler for 1 Hz (32768 - 1 with the LSE) */
    RTC->PRLH = prescaler >> 16;
    RTC->PRLL = prescaler & 0xFFFF;

    /* Set counter to 0 */
    RTC->CNTH = 0;
    RTC->CNTL = 0;

    /* Exit configuration mode */
    RTC->CRL &= ~RTC_CRL_CNF;
    while (!(RTC->CRL & RTC_CRL_RTOFF));
}
```

### Setting the Next Alarm

```c
#define LOG_INTERVAL_SEC 60

void rtc_set_alarm_relative(uint32_t seconds) {
    uint32_t current = ((uint32_t)RTC->CNTH << 16) | RTC->CNTL;
    uint32_t alarm_time = current + seconds;

    while (!(RTC->CRL & RTC_CRL_RTOFF));
    RTC->CRL |= RTC_CRL_CNF;

    RTC->ALRH = (uint16_t)(alarm_time >> 16);
    RTC->ALRL = (uint16_t)(alarm_time & 0xFFFF);

    RTC->CRL &= ~RTC_CRL_CNF;
    while (!(RTC->CRL & RTC_CRL_RTOFF));

    /* Enable alarm interrupt */
    RTC->CRH |= RTC_CRH_ALRIE;

    /* Configure EXTI line 17 for RTC alarm (needed for Stop mode wakeup) */
    EXTI->IMR |= EXTI_IMR_MR17;
    EXTI->RTSR |= EXTI_RTSR_TR17;  /* Rising edge */

    NVIC_SetPriority(RTC_Alarm_IRQn, 1);
    NVIC_EnableIRQ(RTC_Alarm_IRQn);
}

void RTC_Alarm_IRQHandler(void) {
    if (EXTI->PR & EXTI_PR_PR17) {
        EXTI->PR = EXTI_PR_PR17;  /* Clear EXTI pending */
    }
    if (RTC->CRL & RTC_CRL_ALRF) {
        RTC->CRL &= ~RTC_CRL_ALRF;  /* Clear alarm flag */
    }
    /* CPU wakes from Stop mode and continues after WFI */
}
```

## Entering Stop Mode

<InArticleAd />


The order matters. Set the alarm first, or nothing will wake the chip. Put the sensor and the flash chip to sleep: the 14 uA is for the STM32 alone, and every other part adds to it. Then set the deep-sleep bit and run `__WFI()` (wait for interrupt); the program stops on that line until the alarm.

```c
void enter_stop_mode(void) {
    /* Set the next wakeup alarm */
    rtc_set_alarm_relative(LOG_INTERVAL_SEC);

    /* Put BME280 into sleep mode */
    bme280_sleep();

    /* Put W25Q flash into power-down mode */
    w25q_power_down();

    /* Configure Stop mode */
    SCB->SCR |= SCB_SCR_SLEEPDEEP_Msk;  /* Enable deep sleep */

    PWR->CR &= ~PWR_CR_PDDS;    /* Stop mode (not Standby) */
    PWR->CR |= PWR_CR_LPDS;     /* Low-power regulator in Stop */

    /* Clear wakeup flag */
    PWR->CR |= PWR_CR_CWUF;

    /* A SysTick interrupt pending at this moment would end the sleep at once */
    SysTick->CTRL &= ~SysTick_CTRL_ENABLE_Msk;

    /* Enter Stop mode (WFI = Wait For Interrupt) */
    __WFI();

    /* Execution resumes here after RTC alarm wakes us */

    /* Reconfigure clock (HSE + PLL, since Stop mode reverts to HSI) */
    clock_init();
    SysTick->CTRL |= SysTick_CTRL_ENABLE_Msk;

    /* Clear deep sleep bit */
    SCB->SCR &= ~SCB_SCR_SLEEPDEEP_Msk;
}
```

:::caution[Clock after Stop mode]
When the STM32 leaves Stop mode, it runs from the 8 MHz internal oscillator (HSI), not from the 72 MHz clock you set up at the start. Call `clock_init()` again before you use anything whose timing depends on the clock: UART baud rates, SPI speeds, timer periods. If you forget, the serial output after the first wake is unreadable, because every bit is 9 times too long.
:::

## W25Q SPI Flash Driver

<InArticleAd />


The readings must survive a flat battery, so they go to flash memory, which keeps its contents with no power. The W25Q32 is a 4 MB flash chip on the SPI bus.

One flash rule shapes the whole logger: a write can only change a bit from 1 to 0. To get a 1 back you must erase, and the smallest erasable block is a 4 KB sector, which then reads as all 1s (`0xFF` in every byte). So the logger never changes old entries: it writes one after another, and erases each sector just before its first entry.

```text
  +--------+--------+--------+-- --+---------+
  |Sector 0|Sector 1|Sector 2| ... |Sect.1023|
  | 4 KB   | 4 KB   | 4 KB   |     | 4 KB    |
  +--------+--------+--------+-- --+---------+
  |entry 0 |entry256|        |     |         |
  |entry 1 |entry257|        |     |         |
  |  ...   |  ...   |  <-- write pointer     |
  |entry255|        |                        |
  +--------+--------+------------------------+
  0x000000  0x001000  0x002000        0x3FFFFF
```

An entry is 16 bytes, so one sector holds 4096 / 16 = 256 entries and the chip holds about 262,000. At one entry a minute that is 182 days. After the last sector the write pointer returns to the start. The chip also has a power-down mode that reduces its standby current from ~1 uA to ~0.1 uA.

### Flash Commands

Every action starts with a one-byte command sent over SPI while the chip select pin is low.

| Command | Opcode | Description |
|---------|--------|-------------|
| Write Enable | 0x06 | Must precede every write/erase |
| Page Program | 0x02 | Write up to 256 bytes |
| Read Data | 0x03 | Read any number of bytes |
| Sector Erase (4KB) | 0x20 | Erase 4096-byte sector |
| Read Status Reg 1 | 0x05 | Check busy flag (bit 0) |
| Power Down | 0xB9 | Enter low-power mode |
| Release Power Down | 0xAB | Wake from power-down |
| Read JEDEC ID | 0x9F | Manufacturer and device ID |

### Driver Implementation

```c
#define W25Q_CS_LOW()   GPIOA->BRR = (1 << 4)
#define W25Q_CS_HIGH()  GPIOA->BSRR = (1 << 4)

void w25q_write_enable(void) {
    W25Q_CS_LOW();
    spi1_transfer(0x06);
    W25Q_CS_HIGH();
}

/* Returns 1 when the chip is ready, 0 after 500 ms (longer than the
 * slowest sector erase): a missing chip can read as busy for ever */
int w25q_wait_busy(void) {
    uint32_t start = systick_ms;
    int ok = 1;
    W25Q_CS_LOW();
    spi1_transfer(0x05);
    while (spi1_transfer(0xFF) & 0x01) {  /* Wait until BUSY clears */
        if (systick_ms - start > 500) { ok = 0; break; }
    }
    W25Q_CS_HIGH();
    return ok;
}

void w25q_sector_erase(uint32_t addr) {
    w25q_write_enable();
    W25Q_CS_LOW();
    spi1_transfer(0x20);
    spi1_transfer((addr >> 16) & 0xFF);
    spi1_transfer((addr >> 8) & 0xFF);
    spi1_transfer(addr & 0xFF);
    W25Q_CS_HIGH();
    w25q_wait_busy();  /* Sector erase takes 30-400 ms */
}

void w25q_page_program(uint32_t addr, const uint8_t *data, uint16_t len) {
    if (len > 256) len = 256;

    w25q_write_enable();
    W25Q_CS_LOW();
    spi1_transfer(0x02);
    spi1_transfer((addr >> 16) & 0xFF);
    spi1_transfer((addr >> 8) & 0xFF);
    spi1_transfer(addr & 0xFF);
    for (uint16_t i = 0; i < len; i++) {
        spi1_transfer(data[i]);
    }
    W25Q_CS_HIGH();
    w25q_wait_busy();
}

void w25q_read(uint32_t addr, uint8_t *buf, uint16_t len) {
    W25Q_CS_LOW();
    spi1_transfer(0x03);
    spi1_transfer((addr >> 16) & 0xFF);
    spi1_transfer((addr >> 8) & 0xFF);
    spi1_transfer(addr & 0xFF);
    for (uint16_t i = 0; i < len; i++) {
        buf[i] = spi1_transfer(0xFF);
    }
    W25Q_CS_HIGH();
}

void w25q_power_down(void) {
    W25Q_CS_LOW();
    spi1_transfer(0xB9);
    W25Q_CS_HIGH();
}

void w25q_wake(void) {
    W25Q_CS_LOW();
    spi1_transfer(0xAB);
    W25Q_CS_HIGH();
    for (volatile int i = 0; i < 100; i++);  /* tRES1 delay */
}
```

## Data Logger Application

<InArticleAd />


### Log Entry Format

```c
typedef struct __attribute__((packed)) {
    uint32_t timestamp;          /* RTC counter value */
    int16_t  temperature_c10;    /* Celsius x 10 */
    uint16_t pressure_hpa10;     /* hPa x 10 */
    uint16_t humidity_pct10;     /* %RH x 10 */
    uint16_t battery_mv;         /* Battery voltage in mV */
    uint32_t reserved;           /* Padding, written as 0xFFFFFFFF */
} log_entry_t;  /* 16 bytes: divides the 256-byte page and the 4 KB sector
                 * exactly, so an entry never crosses a page or sector */
```

### Write Pointer Management

The write pointer is the flash address of the next free entry. It is kept in two backup registers, 16-bit stores in the same protected domain as the RTC.

```c
#define FLASH_LOG_START   0x000000
#define FLASH_LOG_END     0x3FFFFF   /* 4 MB */
#define SECTOR_SIZE       4096
#define ENTRY_SIZE        sizeof(log_entry_t)
#define ENTRIES_PER_SECTOR (SECTOR_SIZE / ENTRY_SIZE)

/* Store write pointer in backup register (survives Stop mode) */
uint32_t get_write_pointer(void) {
    return (BKP->DR1 | ((uint32_t)BKP->DR2 << 16));
}

void set_write_pointer(uint32_t addr) {
    PWR->CR |= PWR_CR_DBP;  /* Enable backup domain write */
    BKP->DR1 = (uint16_t)(addr & 0xFFFF);
    BKP->DR2 = (uint16_t)(addr >> 16);
}

void log_write_entry(const log_entry_t *entry) {
    uint32_t addr = get_write_pointer();

    /* Erase sector if we are at a sector boundary */
    if ((addr % SECTOR_SIZE) == 0) {
        w25q_sector_erase(addr);
    }

    w25q_page_program(addr, (const uint8_t *)entry, ENTRY_SIZE);

    addr += ENTRY_SIZE;
    if (addr >= FLASH_LOG_END) {
        addr = FLASH_LOG_START;  /* Wrap around */
    }
    set_write_pointer(addr);
}
```

### Main Loop

```c
/* BME280 ctrl_meas (0xF4): temperature x1, pressure x1, mode in bits 1:0 */
int bme280_force_measurement(void) { return i2c1_write_reg(0x76, 0xF4, 0x25); }
int bme280_sleep(void)             { return i2c1_write_reg(0x76, 0xF4, 0x24); }

/* The cell feeds the chip directly, so the battery voltage is VDDA:
 * VDDA = 1200 mV x 4096 / Vrefint code, as in the ADC lesson */
uint16_t read_battery_voltage(void) {
    RCC->APB2ENR |= RCC_APB2ENR_ADC1EN;
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_ADCPRE) | RCC_CFGR_ADCPRE_DIV6;  /* 12 MHz */
    ADC1->CR2 = ADC_CR2_ADON | ADC_CR2_TSVREFE;  /* power on, Vrefint on */
    ADC1->SMPR1 = 0x7 << 21;                     /* CH17: 239.5 cycles */
    ADC1->SQR3 = 17;
    for (volatile int i = 0; i < 1000; i++);     /* settle (over 10 us) */
    ADC1->CR2 |= ADC_CR2_ADON;                   /* start one conversion */
    uint32_t start = systick_ms;
    while (!(ADC1->SR & ADC_SR_EOC)) {
        if (systick_ms - start > 2) return 0;    /* 0 = not known */
    }
    uint16_t code = ADC1->DR;
    ADC1->CR2 = 0;                               /* ADC off while asleep */
    return code ? (uint16_t)(1200UL * 4096 / code) : 0;
}

int main(void) {
    clock_init();
    systick_init();                  /* 1 ms count for the time limits */
    rtc_init();                      /* keeps the count after a reset */
    spi1_init();
    i2c1_init();
    uart_init();
    USART1->CR1 |= USART_CR1_RE;     /* receive too, for the dump command */
    w25q_wake();

    /* A reset (button, watchdog) must not restart the log. The backup
     * registers survive it while power stays; a marker in DR3 says so.
     * Without the marker, find the first empty entry in flash (correct
     * until the log first wraps around). */
    if (BKP->DR3 != 0xA5A5) {
        uint32_t addr = FLASH_LOG_START, ts;
        for (; addr < FLASH_LOG_END; addr += ENTRY_SIZE) {
            w25q_read(addr, (uint8_t *)&ts, 4);
            if (ts == 0xFFFFFFFF) break;
        }
        set_write_pointer(addr < FLASH_LOG_END ? addr : FLASH_LOG_START);
        BKP->DR3 = 0xA5A5;
    }
    int sensor_ok = bme280_init();

    /* After a reset, listen 10 s: press reset, then type d to dump */
    uart_send_string("Data logger. Type d within 10 s to dump the log.\r\n");
    for (uint32_t start = systick_ms; systick_ms - start < 10000; ) {
        if ((USART1->SR & USART_SR_RXNE) && USART1->DR == 'd') {
            cmd_dump_log();
            break;
        }
    }

    while (1) {
        /* Wake flash and sensor */
        w25q_wake();
        if (!sensor_ok) sensor_ok = bme280_init();
        bme280_force_measurement();

        /* Wait for BME280 measurement (9.3 ms at most with x1 settings) */
        uint32_t start = systick_ms;
        while (systick_ms - start < 12);

        /* Read sensor data; on failure store "not known" markers */
        int32_t temp = 0;
        uint32_t press = 0, hum = 0;
        int fresh = sensor_ok && bme280_read(&temp, &press, &hum);
        if (!fresh) sensor_ok = 0;

        /* Read battery voltage via ADC */
        uint16_t batt_mv = read_battery_voltage();

        /* Create log entry (rounded, not cut off, to one decimal) */
        log_entry_t entry = {
            .timestamp = ((uint32_t)RTC->CNTH << 16) | RTC->CNTL,
            .temperature_c10 = fresh ? (int16_t)((temp + (temp < 0 ? -5 : 5)) / 10) : INT16_MIN,
            .pressure_hpa10 = fresh ? (uint16_t)((press + 5) / 10) : 0xFFFF,
            .humidity_pct10 = fresh ? (uint16_t)hum : 0xFFFF,
            .battery_mv = batt_mv,
            .reserved = 0xFFFFFFFF
        };

        /* Write to flash */
        log_write_entry(&entry);

        /* Enter Stop mode until next RTC alarm */
        enter_stop_mode();
    }
}
```

## Retrieving Logged Data

<InArticleAd />


```c
#include <stdio.h>

void cmd_dump_log(void) {
    uint32_t addr = FLASH_LOG_START;
    uint32_t write_ptr = get_write_pointer();
    log_entry_t entry;
    char buf[80];
    uint32_t count = 0;

    uart_send_string("timestamp,temp_c,pressure_hpa,humidity_pct,battery_mv\r\n");

    /* Read from the start of the log up to the write pointer.
     * After the log has wrapped around, the older entries beyond
     * the write pointer are not shown by this simple version. */
    uint32_t total_bytes = write_ptr - FLASH_LOG_START;
    uint32_t entries_to_read = total_bytes / ENTRY_SIZE;

    for (uint32_t i = 0; i < entries_to_read; i++) {
        w25q_read(addr, (uint8_t *)&entry, ENTRY_SIZE);

        /* Skip erased entries (all 0xFF) */
        if (entry.timestamp == 0xFFFFFFFF) {
            addr += ENTRY_SIZE;
            if (addr >= FLASH_LOG_END) addr = FLASH_LOG_START;
            continue;
        }

        /* Sensor did not answer: empty fields, not invented numbers */
        if (entry.temperature_c10 == INT16_MIN) {
            snprintf(buf, sizeof(buf), "%lu,,,,%u\r\n",
                     (unsigned long)entry.timestamp, entry.battery_mv);
            uart_send_string(buf);
            addr += ENTRY_SIZE;
            if (addr >= FLASH_LOG_END) addr = FLASH_LOG_START;
            count++;
            continue;
        }

        int16_t t_whole = entry.temperature_c10 / 10;
        uint16_t t_frac = (entry.temperature_c10 < 0 ? -entry.temperature_c10 : entry.temperature_c10) % 10;
        snprintf(buf, sizeof(buf),
            "%lu,%s%d.%u,%u.%u,%u.%u,%u\r\n",
            (unsigned long)entry.timestamp,
            (entry.temperature_c10 < 0 && t_whole == 0) ? "-" : "",
            t_whole, t_frac,
            entry.pressure_hpa10 / 10, entry.pressure_hpa10 % 10,
            entry.humidity_pct10 / 10, entry.humidity_pct10 % 10,
            entry.battery_mv);
        uart_send_string(buf);

        addr += ENTRY_SIZE;
        if (addr >= FLASH_LOG_END) addr = FLASH_LOG_START;
        count++;
    }

    snprintf(buf, sizeof(buf), "\r\nTotal entries: %lu\r\n", (unsigned long)count);
    uart_send_string(buf);
}
```

### Check it

- After an hour, press reset and type `d`: about 60 lines, timestamps 60 apart (far from 60: the LSI is keeping time). Reset and dump again: the old lines are still there.
- A fresh CR2032 shows `battery_mv` near 3000. With the BME280's SDA wire pulled, entries keep coming with empty sensor fields.
- A multimeter (uA range) in the battery lead shows the sleeping current that decides the life: tens of uA with the LED and regulator removed, mA if a part is still on. Put your numbers into the budget.

### Flash and Option Bytes

Anyone with a debug probe can copy the firmware out of an unprotected chip; read protection (RDP) stops that. It is one of the option bytes, settings kept in their own flash area at 0x1FFF_F800 that the chip reads at reset before your program runs. Others set write protection and the watchdog.

To change an option byte, the code unlocks the flash with two key values, erases the option byte area and writes the new value.

```c
/* Enable read protection (Level 1) */
void enable_read_protection(void) {
    /* WARNING: This prevents SWD readout of flash.
     * Reverting to Level 0 erases all flash contents. */
    FLASH->KEYR = 0x45670123;   /* Unlock flash */
    FLASH->KEYR = 0xCDEF89AB;

    FLASH->OPTKEYR = 0x45670123;  /* Unlock option bytes */
    FLASH->OPTKEYR = 0xCDEF89AB;

    FLASH->CR |= FLASH_CR_OPTER;  /* Option byte erase */
    FLASH->CR |= FLASH_CR_STRT;
    while (FLASH->SR & FLASH_SR_BSY);

    FLASH->CR &= ~FLASH_CR_OPTER;
    FLASH->CR |= FLASH_CR_OPTPG;  /* Option byte program */

    /* Write RDP key for Level 1 (any value except 0xA5) */
    *(volatile uint16_t *)0x1FFFF800 = 0x00FF;

    while (FLASH->SR & FLASH_SR_BSY);
    FLASH->CR &= ~FLASH_CR_OPTPG;
}
```

### Bootloader Basics

A bootloader is a small program that runs first and can load new firmware, so a product in the field can be updated without an ST-Link. The STM32F103 has one built into memory that cannot be erased: hold Boot0 high and reset, and the chip accepts new firmware over USART1.

For a product you may write your own bootloader. It occupies the first few KB of flash, checks that the firmware is complete (with a CRC, a checksum over the whole image) and then jumps to it.

```c
/* Jump to system bootloader from application code */
void jump_to_bootloader(void) {
    /* System memory base address for STM32F103 */
    uint32_t sys_mem_addr = 0x1FFFF000;

    /* Disable all interrupts, and stop SysTick so that it cannot fire
     * into the bootloader */
    __disable_irq();
    SysTick->CTRL = 0;

    /* Reset all peripherals */
    RCC->APB1RSTR = 0xFFFFFFFF;
    RCC->APB1RSTR = 0;
    RCC->APB2RSTR = 0xFFFFFFFF;
    RCC->APB2RSTR = 0;

    /* Set main stack pointer */
    __set_MSP(*(volatile uint32_t *)sys_mem_addr);

    /* Jump to bootloader reset handler */
    void (*bootloader)(void) = (void (*)(void))(*(volatile uint32_t *)(sys_mem_addr + 4));
    bootloader();
}
```

### Production Checklist

| Item | Purpose |
|------|---------|
| Enable read protection (RDP Level 1) | Prevent firmware theft |
| Set watchdog in option bytes | Ensure recovery from firmware hangs |
| Add CRC to firmware image | Detect corrupted flash |
| Implement brown-out detection | Prevent operation at unsafe voltages |
| Remove debug prints | Reduce power consumption and flash usage |
| Verify all peripheral clocks disabled during sleep | Minimize Stop mode current |
| Test battery voltage at startup | Warn or refuse to operate on low battery |
| Add firmware version in a fixed flash location | Enable field identification |

## Reducing Power Consumption Further

<InArticleAd />


### Peripheral Power Management

```c
void peripherals_off(void) {
    /* Set all unused GPIO pins to analog mode FIRST (lowest leakage).
     * This must happen while GPIO clocks are still enabled,
     * otherwise the register writes have no effect. */
    GPIOA->CRL = 0x00000000;
    GPIOA->CRH = 0x00000000;
    GPIOB->CRL = 0x00000000;
    GPIOB->CRH = 0x00000000;
    GPIOC->CRL = 0x00000000;
    GPIOC->CRH = 0x00000000;

    /* Now disable all peripheral clocks except RTC and backup domain */
    RCC->APB1ENR = RCC_APB1ENR_PWREN | RCC_APB1ENR_BKPEN;
    RCC->APB2ENR = 0;
    RCC->AHBENR = 0;
}

void peripherals_on(void) {
    /* Re-enable needed clocks */
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN | RCC_APB2ENR_IOPBEN
                  | RCC_APB2ENR_SPI1EN | RCC_APB2ENR_USART1EN;
    RCC->APB1ENR |= RCC_APB1ENR_I2C1EN | RCC_APB1ENR_PWREN
                  | RCC_APB1ENR_BKPEN;

    /* Reconfigure GPIO pins */
    spi1_gpio_init();
    i2c1_gpio_init();
    uart_gpio_init();
}
```

### Blue Pill Power Optimization

The 14 uA is for the STM32 chip alone. Other Blue Pill parts draw current all the time: the power LED (~2 mA) and the 3.3V regulator, which uses ~5 mA itself (its quiescent current) with no load. Together about 7 mA, 500 times the Stop current: a 220 mAh cell lasts about 31 hours.

For real low-power operation, remove the power LED and the regulator and power the chip directly from the CR2032 at 3V, or design your own board with a regulator of low quiescent current such as the MCP1700 (~1.6 uA).

| Component | Current Draw | Action |
|-----------|-------------|--------|
| AMS1117 regulator | ~5 mA quiescent | Replace with MCP1700 or power MCU directly |
| Power LED | ~2 mA | Desolder or cut trace |
| USB pull-up (R10) | ~2 mA when USB connected | Disconnect USB for battery operation |
| STM32 in Stop mode | ~14 uA | Already optimized |
