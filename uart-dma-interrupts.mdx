A UART holds only one received byte. If the program is busy when the next byte arrives, a byte is lost, and at 115200 baud a new byte arrives every 87 microseconds. A program that checks the UART in its main loop (polling) therefore loses characters as soon as it does real work. In this lesson you build a serial command shell that receives through DMA, hardware that copies each byte into memory without the CPU, and that uses interrupts to know when a whole command has arrived. The shell is then your debugging tool: type a command and the STM32 answers with register values or pin states. #STM32 #UART #DMA

## What We Are Building

<Card title="Interactive Command Shell over Serial" icon="star">
A command line on the Blue Pill that runs commands typed over UART. DMA puts received bytes into a circular buffer (one that starts again at its beginning when full), so none are lost while the CPU works on the previous command. Long answers also go out by DMA, so the program does not wait for each character.

## NVIC and Interrupt Priorities

<InArticleAd />


An interrupt is a hardware signal that stops the main program for a moment, runs a short function (the handler, or ISR, interrupt service routine), and returns, like a doorbell while you cook. The chip reacts at once without checking in a loop.

When two interrupts want to run together, the NVIC (Nested Vectored Interrupt Controller) in the Cortex-M3 core decides. Each interrupt has a priority number; a lower number is more urgent. The STM32F103 has 16 levels, 0 to 15.

### Priority Grouping

An interrupt with a lower priority number stops the running handler of one with a higher number. This is called preemption.

```text
  Priority 1            +-[DMA RX]-+
  Priority 2     +-[TX]-+          +-[TX]-+
  main()    -----+                        +-----
                 ^      ^          ^      ^
                 1      2          3      4

  1. The DMA TX interrupt fires: main() stops.
  2. DMA RX fires. It is more urgent: TX stops.
  3. RX finishes: TX continues.
  4. TX finishes: main() continues.
```

The 4 priority bits can be split in two. The preemption priority decides which interrupt can stop another. The sub-priority only orders two that wait at the same moment; it never stops a running handler.

| Group Setting | Preemption Bits | Sub-priority Bits | Preemption Levels |
|---------------|----------------|-------------------|-------------------|
| Group 4 (default) | 4 | 0 | 16 levels, no sub-priority |
| Group 3 | 3 | 1 | 8 levels, 2 sub-priorities |
| Group 2 | 2 | 2 | 4 levels, 4 sub-priorities |

### Setting Priorities for This Project

Receiving is more urgent than sending: a late answer harms nobody, a lost byte is gone. In `NVIC_EncodePriority(5, 1, 0)` the numbers are the grouping value, the preemption priority and the sub-priority. Both receive interrupts get preemption priority 1, so neither stops the other, and both can stop the transmit interrupt at 2.

```c
void nvic_config(void) {
    /* Use priority group 2: 4 preemption levels, 4 sub-priority levels */
    NVIC_SetPriorityGrouping(5);  /* 5 means group 2 on Cortex-M3 */

    /* DMA1 Channel 5 (USART1 RX): high priority */
    NVIC_SetPriority(DMA1_Channel5_IRQn, NVIC_EncodePriority(5, 1, 0));
    NVIC_EnableIRQ(DMA1_Channel5_IRQn);

    /* DMA1 Channel 4 (USART1 TX): medium priority */
    NVIC_SetPriority(DMA1_Channel4_IRQn, NVIC_EncodePriority(5, 2, 0));
    NVIC_EnableIRQ(DMA1_Channel4_IRQn);

    /* USART1 (idle line detection): high priority */
    NVIC_SetPriority(USART1_IRQn, NVIC_EncodePriority(5, 1, 1));
    NVIC_EnableIRQ(USART1_IRQn);
}
```

## DMA Fundamentals

<InArticleAd />


An interrupt for every byte would stop the CPU 11,520 times a second at 115200 baud. DMA (Direct Memory Access) avoids this: a hardware block that copies data between a peripheral and memory by itself, like a conveyor belt that moves boxes while the worker does other work. Each time the UART has a byte, the DMA controller puts it in the next place of a buffer and reduces a count by one.

```text
  +----------+     +-----------+     +--------+
  | USART1   |     |  DMA1     |     |  SRAM  |
  | DR reg   |---->| Channel 5 |---->| rx_buf |
  | (CPAR)   |     |           |     | (CMAR) |
  +----------+     | CNDTR=256 |     +--------+
                   | (count)   |
  Peripheral       +-----------+     Memory
  address fixed,                     address
  no increment                       increments

  In circular mode the count reloads and
  writing starts again at the start of rx_buf.
```

The CPU only sets up the transfer: source, destination, number of bytes and direction. DMA1 on the STM32F103 has 7 channels, each wired to fixed peripherals, so you cannot choose: USART1 receive is always channel 5.

### DMA1 Channel Assignments (Relevant Channels)

| Channel | Peripheral Request |
|---------|-------------------|
| Channel 1 | ADC1 |
| Channel 2 | SPI1_RX / USART3_TX / TIM1_CH1 |
| Channel 3 | SPI1_TX / USART3_RX / TIM1_CH2 |
| Channel 4 | SPI2_RX / USART1_TX / TIM1_CH4 |
| Channel 5 | SPI2_TX / USART1_RX / TIM1_UP |
| Channel 6 | USART2_RX / TIM1_CH3 |
| Channel 7 | USART2_TX |

### DMA Configuration Registers

Each DMA channel has four key registers:

- **CCR** (Channel Configuration Register): direction, circular mode, memory/peripheral increment, data size, priority, enable
- **CNDTR** (Number of Data Register): how many transfers to perform
- **CPAR** (Peripheral Address Register): the peripheral data register address
- **CMAR** (Memory Address Register): the memory buffer address

## UART Receive with DMA (Circular Buffer)

<InArticleAd />


### Why Circular Mode

In normal mode the transfer stops when CNDTR reaches zero, and bytes that arrive before you set up the channel again are lost. In circular mode the DMA controller reloads CNDTR itself and continues at the start of the buffer, so receiving never stops.

One limit remains: the buffer holds 256 bytes. If the program does not read them before 256 more arrive (22 ms of continuous data at 115200 baud), the oldest unread bytes are overwritten.

### Implementation

```c
#define RX_BUF_SIZE 256

uint8_t rx_dma_buf[RX_BUF_SIZE];
volatile uint16_t rx_read_pos = 0;

void uart_dma_rx_init(void) {
    /* Enable DMA1 clock */
    RCC->AHBENR |= RCC_AHBENR_DMA1EN;

    /* Configure DMA1 Channel 5 for USART1 RX */
    DMA1_Channel5->CCR = 0;  /* Disable channel first */

    DMA1_Channel5->CPAR = (uint32_t)&USART1->DR;   /* Source: USART data reg */
    DMA1_Channel5->CMAR = (uint32_t)rx_dma_buf;     /* Destination: RAM buffer */
    DMA1_Channel5->CNDTR = RX_BUF_SIZE;

    DMA1_Channel5->CCR = DMA_CCR_MINC     /* Memory increment */
                       | DMA_CCR_CIRC     /* Circular mode */
                       | DMA_CCR_TCIE     /* Transfer complete interrupt */
                       | DMA_CCR_HTIE;    /* Half transfer interrupt */

    DMA1_Channel5->CCR |= DMA_CCR_EN;     /* Enable channel */

    /* Enable USART1 DMA receiver */
    USART1->CR3 |= USART_CR3_DMAR;

    /* Enable the receiver (uart_init() from the menu program enabled TX only)
     * and the USART1 IDLE line interrupt */
    USART1->CR1 |= USART_CR1_RE | USART_CR1_IDLEIE;
}
```

### Processing Received Data

The DMA controller writes into the buffer; the program reads from it. CNDTR counts down from 256, so the write position is 256 minus CNDTR. `rx_read_pos` is where the program has read up to, and the bytes between the two positions are waiting.

```c
uint16_t uart_dma_available(void) {
    uint16_t write_pos = RX_BUF_SIZE - DMA1_Channel5->CNDTR;
    if (write_pos >= rx_read_pos) {
        return write_pos - rx_read_pos;
    } else {
        return RX_BUF_SIZE - rx_read_pos + write_pos;
    }
}

uint8_t uart_dma_read_byte(void) {
    uint8_t byte = rx_dma_buf[rx_read_pos];
    rx_read_pos = (rx_read_pos + 1) % RX_BUF_SIZE;
    return byte;
}

uint16_t uart_dma_read_line(char *dest, uint16_t max_len) {
    uint16_t count = 0;
    while (uart_dma_available() > 0 && count < max_len - 1) {
        char c = (char)uart_dma_read_byte();
        if (c == '\n' || c == '\r') {
            if (count > 0) break;  /* End of line */
            continue;              /* Skip leading newlines */
        }
        dest[count++] = c;
    }
    dest[count] = '\0';
    return count;
}
```

### Idle Line Detection

The DMA controller does not know when a command is complete; the UART does. Its idle line interrupt fires when the RX line stays quiet for one byte time (87 microseconds here) after data. A terminal sends a command as a group of characters and then nothing, so the silence marks the end.

```text
  RX line:  ____  __ __ __ __ __  ____________
                 |__|  |__|  |__|
                  h  e  l  p  \n
                 <--- data --->  <-- idle -->
                                     ^
                          IDLE interrupt fires here
```

At that moment the buffer holds the whole command, between the read position and the write position:

```text
  +---+---+---+---+---+---+---+---+
  | h | e | l | p |\n |   |   |   |
  +---+---+---+---+---+---+---+---+
    ^                   ^
    read_pos            write_pos (= 256 - CNDTR)
```

The handler only sets a flag, `rx_data_ready`; the main loop does the slow work of reading the command. Keep every handler this short, so other interrupts are not delayed.

```c
volatile uint8_t rx_data_ready = 0;

void USART1_IRQHandler(void) {
    if (USART1->SR & USART_SR_IDLE) {
        /* Clear idle flag by reading SR then DR */
        (void)USART1->SR;
        (void)USART1->DR;

        rx_data_ready = 1;
    }
}

void DMA1_Channel5_IRQHandler(void) {
    if (DMA1->ISR & DMA_ISR_TCIF5) {
        DMA1->IFCR = DMA_IFCR_CTCIF5;
        /* Buffer wrapped around; data is still valid in circular mode */
    }
    if (DMA1->ISR & DMA_ISR_HTIF5) {
        DMA1->IFCR = DMA_IFCR_CHTIF5;
        /* Half buffer filled; useful for double-buffer processing */
    }
}
```

## UART Transmit with DMA

<InArticleAd />

Sending is the same transfer in the other direction: give the text address and length, then enable the channel. In normal mode it stops after the last byte, and its interrupt clears `tx_busy`. The text must not change until then, because the DMA controller is still reading it.

```c
volatile uint8_t tx_busy = 0;

void uart_dma_tx_init(void) {
    /* Enable DMA1 clock (harmless if it is already on) */
    RCC->AHBENR |= RCC_AHBENR_DMA1EN;

    /* DMA1 Channel 4 for USART1 TX */
    DMA1_Channel4->CCR = 0;

    DMA1_Channel4->CPAR = (uint32_t)&USART1->DR;
    DMA1_Channel4->CCR = DMA_CCR_MINC       /* Memory increment */
                       | DMA_CCR_DIR        /* Read from memory */
                       | DMA_CCR_TCIE;      /* Transfer complete interrupt */

    /* Enable USART1 DMA transmitter */
    USART1->CR3 |= USART_CR3_DMAT;
}

void uart_dma_send(const char *data, uint16_t len) {
    /* Wait for previous transfer to complete */
    while (tx_busy);

    tx_busy = 1;
    DMA1_Channel4->CCR &= ~DMA_CCR_EN;
    DMA1_Channel4->CMAR = (uint32_t)data;
    DMA1_Channel4->CNDTR = len;
    DMA1_Channel4->CCR |= DMA_CCR_EN;
}

void DMA1_Channel4_IRQHandler(void) {
    if (DMA1->ISR & DMA_ISR_TCIF4) {
        DMA1->IFCR = DMA_IFCR_CTCIF4;
        DMA1_Channel4->CCR &= ~DMA_CCR_EN;
        tx_busy = 0;
    }
}
```

## Command Parser

<InArticleAd />


```c
#include <string.h>
#include <stdio.h>

/* Simple string comparison for first N characters */
static int starts_with(const char *str, const char *prefix) {
    return strncmp(str, prefix, strlen(prefix)) == 0;
}

/* Parse integer from string, return pointer to next character */
static const char *parse_int(const char *s, int32_t *out) {
    int32_t val = 0;
    int neg = 0;
    while (*s == ' ') s++;
    if (*s == '-') { neg = 1; s++; }
    while (*s >= '0' && *s <= '9') {
        val = val * 10 + (*s - '0');
        s++;
    }
    *out = neg ? -val : val;
    return s;
}

static char tx_buf[512];  /* Transmit buffer for DMA */

void cmd_help(void) {
    const char *msg =
        "\r\n=== STM32 Command Shell ===\r\n"
        "Commands:\r\n"
        "  help              Show this help\r\n"
        "  pwm <ch> <duty>   Set TIM2 channel PWM (0-100%)\r\n"
        "  read <port><pin>  Read GPIO pin (e.g., read A5)\r\n"
        "  dump <periph>     Dump registers (RCC, GPIOA, TIM2)\r\n"
        "  reset             Software reset\r\n\r\n";
    uart_dma_send(msg, strlen(msg));
}

void cmd_pwm(const char *args) {
    int32_t channel, duty;
    args = parse_int(args, &channel);
    args = parse_int(args, &duty);

    if (channel < 1 || channel > 4 || duty < 0 || duty > 100) {
        const char *err = "Error: pwm <1-4> <0-100>\r\n";
        uart_dma_send(err, strlen(err));
        return;
    }

    uint16_t ccr_val = (uint16_t)((TIM2->ARR + 1) * duty / 100);

    switch (channel) {
        case 1: TIM2->CCR1 = ccr_val; break;
        case 2: TIM2->CCR2 = ccr_val; break;
        case 3: TIM2->CCR3 = ccr_val; break;
        case 4: TIM2->CCR4 = ccr_val; break;
    }

    int len = snprintf(tx_buf, sizeof(tx_buf),
        "PWM CH%ld set to %ld%% (CCR=%u)\r\n",
        (long)channel, (long)duty, ccr_val);
    uart_dma_send(tx_buf, len);
}

void cmd_read_pin(const char *args) {
    while (*args == ' ') args++;

    char port_letter = *args++;
    int32_t pin;
    parse_int(args, &pin);

    GPIO_TypeDef *port = NULL;
    switch (port_letter) {
        case 'A': case 'a': port = GPIOA; break;
        case 'B': case 'b': port = GPIOB; break;
        case 'C': case 'c': port = GPIOC; break;
    }

    if (!port || pin < 0 || pin > 15) {
        const char *err = "Error: read <A-C><0-15>\r\n";
        uart_dma_send(err, strlen(err));
        return;
    }

    uint8_t state = (port->IDR >> pin) & 1;
    int len = snprintf(tx_buf, sizeof(tx_buf),
        "P%c%ld = %d\r\n", port_letter, (long)pin, state);
    uart_dma_send(tx_buf, len);
}

void cmd_dump_rcc(void) {
    int len = snprintf(tx_buf, sizeof(tx_buf),
        "RCC Registers:\r\n"
        "  CR     = 0x%08lX\r\n"
        "  CFGR   = 0x%08lX\r\n"
        "  APB2ENR= 0x%08lX\r\n"
        "  APB1ENR= 0x%08lX\r\n"
        "  AHBENR = 0x%08lX\r\n",
        (unsigned long)RCC->CR,
        (unsigned long)RCC->CFGR,
        (unsigned long)RCC->APB2ENR,
        (unsigned long)RCC->APB1ENR,
        (unsigned long)RCC->AHBENR);
    uart_dma_send(tx_buf, len);
}

void process_command(const char *cmd) {
    if (starts_with(cmd, "help")) {
        cmd_help();
    } else if (starts_with(cmd, "pwm")) {
        cmd_pwm(cmd + 3);
    } else if (starts_with(cmd, "read")) {
        cmd_read_pin(cmd + 4);
    } else if (starts_with(cmd, "dump RCC") || starts_with(cmd, "dump rcc")) {
        cmd_dump_rcc();
    } else if (starts_with(cmd, "reset")) {
        NVIC_SystemReset();
    } else {
        const char *err = "Unknown command. Type 'help' for list.\r\n";
        uart_dma_send(err, strlen(err));
    }
}
```

## Main Application

<InArticleAd />

The main loop works only when the flag says a command has arrived. Between commands, `__WFI()` (wait for interrupt) stops the CPU until the next interrupt, which saves power.

```c
int main(void) {
    clock_init();
    systick_init();
    nvic_config();

    /* USART1 basic init (baud rate, TX/RX enable) */
    uart_init();

    /* DMA-based RX and TX */
    uart_dma_rx_init();
    uart_dma_tx_init();

    /* PWM on TIM2 for the 'pwm' command to control */
    servo_pwm_init();

    cmd_help();  /* Print welcome message */

    char cmd_buf[128];

    while (1) {
        if (rx_data_ready) {
            rx_data_ready = 0;

            /* Read all available lines */
            while (uart_dma_available() > 0) {
                uint16_t len = uart_dma_read_line(cmd_buf, sizeof(cmd_buf));
                if (len > 0) {
                    /* Do not overwrite tx_buf while DMA is still sending it */
                    while (tx_busy);

                    /* Echo the command */
                    int echo_len = snprintf(tx_buf, sizeof(tx_buf),
                        "> %s\r\n", cmd_buf);
                    uart_dma_send(tx_buf, echo_len);

                    /* Wait for echo to finish before processing */
                    while (tx_busy);

                    process_command(cmd_buf);
                }
            }
        }

        /* CPU is free for other tasks here */
        __WFI();  /* Wait for interrupt (low power idle) */
    }
}
```
