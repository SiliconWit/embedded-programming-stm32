A battery voltage rises above its safe limit for two thousandths of a second. A program that reads the voltage four times a second almost never sees it. In this lesson the chip measures without stopping and stores each result in memory by itself. You then add the analog watchdog, a hardware check that interrupts the program within microseconds when a reading leaves the range you set. #STM32 #ADC #AnalogWatchdog

## What We Are Building

<Card title="Voltage and Current Monitor with Threshold Alerts" icon="star">
A monitor that reads a voltage from a potentiometer (a variable resistor turned by hand) and a current from an INA219 sensor module. The analog-to-digital converter (ADC) measures three inputs in turn, without stopping: the potentiometer, the chip's internal temperature sensor and its internal reference voltage. The analog watchdog raises an alert (LED and serial warning) when the potentiometer voltage passes your limit.

## STM32F103 ADC Architecture

<InArticleAd />


An ADC turns a voltage into a whole number. This one has 12 bits, so it divides the range from 0 V to the reference voltage (3.3 V here) into 4096 steps of about 0.8 mV. The result, called a code, runs from 0 to 4095.

The ADC has one result register, `ADC1->DR`, and each conversion overwrites the last; a program that copies each result itself loses one whenever it is late. DMA (direct memory access) copies each value to memory with no processor instruction, like a clerk who files each form as it arrives. In scan mode the ADC converts a list of channels in order, and DMA puts each result in its own place in an array.

```text
  ADC continuous scan with DMA:

  +------+   +------+   +------+
  | CH0  |-->| CH16 |-->| CH17 |--+
  | PA0  |   | Temp |   | Vref |  |
  +------+   +------+   +------+  |
     ^                             |
     |          scan repeats       |
     +-----------------------------+

  DMA1 Channel 1 transfers:
  ADC1->DR --> adc_values[0]  (CH0)
  ADC1->DR --> adc_values[1]  (CH16)
  ADC1->DR --> adc_values[2]  (CH17)
  (circular: restarts automatically)
```

Of the two ADCs in the STM32F103, only ADC1 has its own DMA channel (DMA1 Channel 1), so this lesson uses ADC1. One scan can hold up to 16 channels.

### ADC Clock Requirements

The ADC needs time for each measurement, so its clock must be between 0.6 MHz and 14 MHz; a faster clock gives wrong readings. It comes from the 72 MHz APB2 clock through a prescaler (a divider):

| APB2 Clock | Prescaler | ADC Clock |
|------------|-----------|-----------|
| 72 MHz | /6 | 12 MHz |
| 72 MHz | /8 | 9 MHz |

Use /6. It gives 12 MHz, the fastest clock inside the limit (/4 would give 18 MHz).

### Channel Assignment

| Channel | Source | Notes |
|---------|--------|-------|
| CH0 | PA0 | Potentiometer, 0 V to 3.3 V |
| CH16 | Internal temp sensor | ~1.43V at 25C, falls 4.3 mV for each degree of rise |
| CH17 | Internal Vrefint | A fixed ~1.20V, used to check the supply |

Channel 17 matters on a battery. The ADC measures every input against the supply, like a ruler as long as the supply voltage, and Vrefint is a stick that stays 1.20 V long. When the supply falls, the ruler shrinks and the code for Vrefint rises. At 3.3 V the code is 1.20 / 3.3 × 4096 = 1489. The real supply is 1.20 V × 4096 / code.

## Multi-Channel ADC with DMA

<InArticleAd />


### ADC Initialization

The sample time is how long the ADC stays connected to the input before it measures. The longest, 239.5 clock cycles, is the most accurate, and the two internal channels need it. One conversion then takes 239.5 + 12.5 = 252 cycles, which is 21 µs at 12 MHz. A scan of three channels takes 63 µs.

```c
#define ADC_CHANNELS 3

volatile uint16_t adc_values[ADC_CHANNELS];  /* DMA destination */

void adc_init(void) {
    /* Enable clocks */
    RCC->APB2ENR |= RCC_APB2ENR_ADC1EN | RCC_APB2ENR_IOPAEN;
    RCC->AHBENR  |= RCC_AHBENR_DMA1EN;

    /* ADC clock prescaler: 72 MHz / 6 = 12 MHz */
    RCC->CFGR &= ~RCC_CFGR_ADCPRE;
    RCC->CFGR |= RCC_CFGR_ADCPRE_DIV6;

    /* PA0 as analog input */
    GPIOA->CRL &= ~(0xF << 0);  /* MODE=00, CNF=00 = analog */

    /* ADC1 configuration */
    ADC1->CR2 = ADC_CR2_ADON;   /* Power on ADC (first write) */
    for (volatile int i = 0; i < 10000; i++);  /* Stabilization delay */

    /* Enable temperature sensor and Vrefint */
    ADC1->CR2 |= ADC_CR2_TSVREFE;

    /* Scan mode, continuous conversion, DMA enable */
    ADC1->CR1 |= ADC_CR1_SCAN;
    ADC1->CR2 |= ADC_CR2_CONT | ADC_CR2_DMA;

    /* Sequence: 3 channels */
    ADC1->SQR1 = (ADC_CHANNELS - 1) << 20;  /* Length = 3 */
    ADC1->SQR3 = (0  << 0)    /* SQ1 = CH0 (PA0) */
               | (16 << 5)    /* SQ2 = CH16 (temp) */
               | (17 << 10);  /* SQ3 = CH17 (Vref) */

    /* Sample time: 239.5 cycles for all channels (accurate readings) */
    ADC1->SMPR2 |= (0x7 << 0);     /* CH0 */
    ADC1->SMPR1 |= (0x7 << 18)     /* CH16 */
                 |  (0x7 << 21);    /* CH17 */

    /* Calibrate ADC */
    ADC1->CR2 |= ADC_CR2_RSTCAL;
    while (ADC1->CR2 & ADC_CR2_RSTCAL);
    ADC1->CR2 |= ADC_CR2_CAL;
    while (ADC1->CR2 & ADC_CR2_CAL);
}
```

### DMA Configuration for ADC

A DMA channel needs three facts: where to copy from (`CPAR`, the ADC result register), where to copy to (`CMAR`, the array) and how many values (`CNDTR`). Circular mode returns to element 0 after the last one, so the array always holds the newest scan.

```c
void adc_dma_init(void) {
    /* DMA1 Channel 1 (ADC1) */
    DMA1_Channel1->CCR = 0;  /* Disable first */

    DMA1_Channel1->CPAR = (uint32_t)&ADC1->DR;
    DMA1_Channel1->CMAR = (uint32_t)adc_values;
    DMA1_Channel1->CNDTR = ADC_CHANNELS;

    DMA1_Channel1->CCR = DMA_CCR_MINC      /* Memory increment */
                       | DMA_CCR_PSIZE_0   /* Peripheral size: 16-bit */
                       | DMA_CCR_MSIZE_0   /* Memory size: 16-bit */
                       | DMA_CCR_CIRC      /* Circular mode */
                       | DMA_CCR_TCIE;     /* Transfer complete interrupt */

    DMA1_Channel1->CCR |= DMA_CCR_EN;

    NVIC_SetPriority(DMA1_Channel1_IRQn, 2);
    NVIC_EnableIRQ(DMA1_Channel1_IRQn);

    /* Start continuous ADC conversion */
    ADC1->CR2 |= ADC_CR2_ADON;  /* Start conversion (second write) */
}

void DMA1_Channel1_IRQHandler(void) {
    if (DMA1->ISR & DMA_ISR_TCIF1) {
        DMA1->IFCR = DMA_IFCR_CTCIF1;
        /* adc_values[] is now updated with fresh readings */
        /* CH0 = adc_values[0], Temp = adc_values[1], Vref = adc_values[2] */
    }
}
```

## Analog Watchdog

<InArticleAd />


The main loop looks four times a second, so a 2 ms rise falls between two looks: a guard who looks in now and then, where you need a smoke alarm. The analog watchdog is that alarm: hardware in the ADC that compares every conversion with a high threshold (register `HTR`) and a low threshold (register `LTR`).

```text
  ADC code
  4095 |
       |             * *    <- above HTR:
  3000 +-----------*-----*----- interrupt
  HTR  |         *         *
       |    *  *             *
       |  *                    *
   100 +-----------------------------
  LTR  |
     0 +-------------------------> time
```

A result above `HTR` or below `LTR` sets a flag and, if allowed, interrupts the program. No code runs for the comparison, so the alert comes within one scan (63 µs here).

While the voltage stays high, every scan is out of range: about 16,000 interrupts a second. So the handler switches its interrupt off after the first alert, and the main loop switches it on again once the reading is 100 codes (about 80 mV) back inside the band.

A threshold is a code, not a voltage. For a limit of 2.4 V: 2.4 / 3.3 × 4096 = 2979, rounded here to 3000.

### Watchdog Configuration

```c
#define AWD_HIGH_THRESHOLD  3000  /* ~2.4V at 3.3V reference */
#define AWD_LOW_THRESHOLD   100   /* ~0.08V (near ground fault) */

void analog_watchdog_init(void) {
    /* Monitor single channel (CH0 = PA0) */
    ADC1->CR1 |= ADC_CR1_AWDSGL;    /* Single channel mode */
    ADC1->CR1 &= ~ADC_CR1_AWDCH;    /* Channel 0 */
    ADC1->CR1 |= ADC_CR1_AWDEN;     /* Enable on regular channels */

    /* Set thresholds */
    ADC1->HTR = AWD_HIGH_THRESHOLD;
    ADC1->LTR = AWD_LOW_THRESHOLD;

    /* Enable analog watchdog interrupt */
    ADC1->CR1 |= ADC_CR1_AWDIE;

    NVIC_SetPriority(ADC1_2_IRQn, 0);  /* Highest priority */
    NVIC_EnableIRQ(ADC1_2_IRQn);
}

volatile uint8_t threshold_alert = 0;  /* new alert, not yet printed */
volatile uint8_t alert_active = 0;     /* 1 until the reading is back in the band */

void ADC1_2_IRQHandler(void) {
    if (ADC1->SR & ADC_SR_AWD) {
        ADC1->SR = ~ADC_SR_AWD;        /* Clear flag (it clears when 0 is written) */
        ADC1->CR1 &= ~ADC_CR1_AWDIE;   /* One alert, not one every scan */

        threshold_alert = 1;
        alert_active = 1;

        /* Immediate response: alert LED on */
        GPIOC->BRR = (1 << 13);        /* PC13 low = LED on */
    }
}
```

## Software Oversampling

<InArticleAd />


Every reading carries a little random noise. Oversampling combines many readings of the same input; the noise is as often above the true value as below it, so it partly cancels in the sum.

- Add 4 readings and divide by 2: about 1 more bit of resolution (13 bits).
- Add 16 readings and divide by 4: about 2 more bits (14 bits).

The STM32F103 has no hardware for this, so do it in software with a DMA array 16 scans long. Circular mode keeps it full, the channels stored in turn: CH0, CH16, CH17, CH0 and so on. Reading number `i` of a channel is at index `i * 3 + channel`.

```c
#define OVERSAMPLE_COUNT 16
#define ADC_BUF_SIZE (ADC_CHANNELS * OVERSAMPLE_COUNT)

volatile uint16_t adc_raw_buf[ADC_BUF_SIZE];

/* To fill this buffer, point DMA1_Channel1->CMAR at adc_raw_buf
 * and set CNDTR = ADC_BUF_SIZE in adc_dma_init(). */

/* Average N samples for each channel.
 * This plain average keeps a 12-bit result with less noise.
 * For a 14-bit result, return (sum >> 2) instead. */
uint16_t adc_get_averaged(uint8_t channel) {
    uint32_t sum = 0;
    for (int i = 0; i < OVERSAMPLE_COUNT; i++) {
        sum += adc_raw_buf[i * ADC_CHANNELS + channel];
    }
    return (uint16_t)(sum / OVERSAMPLE_COUNT);
}
```

## INA219 Current Sensor (I2C)

<InArticleAd />


An ADC measures voltage, not current. To measure a current, pass it through a small known resistor (a shunt) and measure the voltage across it: 20 mV across 0.1 Ω means 0.2 A.

The INA219 does this for you. The shunt sits in the positive supply wire before the load (high-side measurement); the chip measures the shunt voltage and the supply (bus) voltage with its own 12-bit ADC and sends the results over I2C.

```text
  V_supply ──┬──[shunt 0.1 Ω]──┬── Load ── GND
             │                 │
        ┌────┴─────────────────┴────┐
        │  VIN+               VIN-  │
        │           INA219          │
        │  VCC    GND    SDA   SCL  │
        └───┬──────┬──────┬─────┬───┘
            │      │      │     │
          3.3V    GND    PB7   PB6
```

Most boards carry a 0.1 Ω shunt. The chip accepts up to 320 mV across it, so the largest current is 0.32 V / 0.1 Ω = 3.2 A.

### INA219 Driver

```c
#include <stdio.h>

/* i2c1_wait() and i2c1_fail() are the 10 ms time limit of the BME280 driver */
int i2c1_write_reg16(uint8_t addr, uint8_t reg, uint16_t val)
{
    I2C1->CR1 |= I2C_CR1_START;
    if (!i2c1_wait(I2C_SR1_SB)) return i2c1_fail();
    I2C1->DR = addr << 1;
    if (!i2c1_wait(I2C_SR1_ADDR)) return i2c1_fail();
    (void)I2C1->SR2;
    I2C1->DR = reg;
    if (!i2c1_wait(I2C_SR1_TXE)) return i2c1_fail();
    I2C1->DR = (val >> 8) & 0xFF;
    if (!i2c1_wait(I2C_SR1_TXE)) return i2c1_fail();
    I2C1->DR = val & 0xFF;
    if (!i2c1_wait(I2C_SR1_TXE)) return i2c1_fail();
    I2C1->CR1 |= I2C_CR1_STOP;
    return 1;
}

/* Returns 1 with the value in *val, or 0 when the chip did not answer */
int i2c1_read_reg16(uint8_t addr, uint8_t reg, uint16_t *val)
{
    uint8_t buf[2];
    if (!i2c1_read_burst(addr, reg, buf, 2)) return 0;
    *val = (buf[0] << 8) | buf[1];
    return 1;
}

#define INA219_ADDR 0x40

#define INA219_REG_CONFIG    0x00
#define INA219_REG_SHUNT_V  0x01
#define INA219_REG_BUS_V    0x02
#define INA219_REG_POWER    0x03
#define INA219_REG_CURRENT  0x04
#define INA219_REG_CALIB    0x05

void ina219_init(void) {
    /* Reset */
    uint16_t config = 0x8000;  /* Reset bit */
    i2c1_write_reg16(INA219_ADDR, INA219_REG_CONFIG, config);
    for (volatile int i = 0; i < 100000; i++);

    /* Configuration: 32V range, 320mV shunt range, 12-bit, continuous */
    config = (0x1 << 13)    /* Bus voltage range: 32V */
           | (0x3 << 11)    /* Shunt voltage range: 320 mV */
           | (0x3 << 7)     /* Bus ADC: 12-bit */
           | (0x3 << 3)     /* Shunt ADC: 12-bit */
           | (0x7);         /* Mode: continuous shunt + bus */
    i2c1_write_reg16(INA219_ADDR, INA219_REG_CONFIG, config);

    /* Calibration for 0.1 ohm shunt, 0.1 mA/LSB */
    /* Cal = trunc(0.04096 / (Current_LSB * R_shunt)) */
    /* Cal = trunc(0.04096 / (0.0001 * 0.1)) = 4096 */
    i2c1_write_reg16(INA219_ADDR, INA219_REG_CALIB, 4096);
}

#define INA219_NOT_KNOWN  (-32768)  /* returned when the chip did not answer */

int16_t ina219_read_current_ma(void) {
    uint16_t raw;
    if (!i2c1_read_reg16(INA219_ADDR, INA219_REG_CURRENT, &raw)) return INA219_NOT_KNOWN;
    /* Current register LSB = 0.1 mA (signed): round to whole mA */
    int16_t i = (int16_t)raw;
    return (int16_t)((i >= 0 ? i + 5 : i - 5) / 10);
}

int32_t ina219_read_bus_voltage_mv(void) {
    uint16_t raw;
    if (!i2c1_read_reg16(INA219_ADDR, INA219_REG_BUS_V, &raw)) return INA219_NOT_KNOWN;
    /* Bus voltage is in bits [15:3], LSB = 4 mV */
    return (raw >> 3) * 4;
}
```

## Converting ADC Readings to Physical Units

<InArticleAd />


The voltage is the code multiplied by the size of one step. The temperature sensor gives 1430 mV at 25 °C and 4.3 mV less for each degree above that. The second function returns the temperature multiplied by 10, which keeps one decimal place in whole-number arithmetic.

```c
/* The exact divisor is 4096 (one step = 3300 / 4096 mV). Dividing by
 * 4095 reads 0.02% high, far less than the error of the ADC itself. */
/* Convert ADC reading to millivolts (3.3V reference) */
uint32_t adc_to_mv(uint16_t adc_val) {
    return (uint32_t)adc_val * 3300 / 4095;
}

/* Internal temperature sensor (from datasheet) */
int32_t adc_to_temp_c10(uint16_t adc_val) {
    /* V_sense = adc_val * 3300 / 4095 (in mV) */
    /* T(C) = (V25 - V_sense) / Avg_Slope + 25 */
    /* V25 = 1430 mV, Avg_Slope = 4.3 mV/C */
    int32_t v_sense = (int32_t)adc_val * 3300 / 4095;
    return ((1430 - v_sense) * 100) / 43 + 250;  /* Result in C x 10 */
}
```

## Main Application

<InArticleAd />


`__WFI()` (wait for interrupt) stops the processor until the next interrupt.

```c
int main(void) {
    clock_init();
    systick_init();
    uart_init();
    i2c1_init();

    /* LED on PC13 as alert indicator */
    RCC->APB2ENR |= RCC_APB2ENR_IOPCEN;
    GPIOC->CRH &= ~(0xF << 20);
    GPIOC->CRH |= (0x3 << 20);
    GPIOC->BSRR = (1 << 13);  /* LED off (active low) */

    adc_init();
    analog_watchdog_init();
    adc_dma_init();
    ina219_init();

    char buf[128];
    uint32_t last_print = 0;

    uart_send_string("\r\n=== Voltage/Current Monitor ===\r\n\r\n");

    while (1) {
        if ((systick_ms - last_print) >= 250) {  /* 4 Hz update */
            last_print = systick_ms;

            uint16_t pot_adc = adc_values[0];
            uint32_t pot_mv = adc_to_mv(pot_adc);
            int32_t temp_c10 = adc_to_temp_c10(adc_values[1]);
            long t = temp_c10 < 0 ? -(long)temp_c10 : (long)temp_c10;
            /* Supply from Vrefint (1.20 V): VDDA = 1200 x 4096 / code */
            uint32_t vdda_mv = 1200UL * 4096 / (adc_values[2] ? adc_values[2] : 1);

            int16_t current_ma = ina219_read_current_ma();
            int32_t bus_mv = ina219_read_bus_voltage_mv();

            snprintf(buf, sizeof(buf),
                "POT: %lumV (ADC:%u) | Temp: %s%ld.%ldC | VDDA: %lumV | ",
                (unsigned long)pot_mv, pot_adc,
                temp_c10 < 0 ? "-" : "", t / 10, t % 10,
                (unsigned long)vdda_mv);
            uart_send_string(buf);

            if (current_ma == INA219_NOT_KNOWN || bus_mv == INA219_NOT_KNOWN) {
                uart_send_string("INA219: no answer");   /* no number is better than a wrong one */
            } else {
                snprintf(buf, sizeof(buf), "I: %dmA | Vbus: %ldmV",
                         current_ma, (long)bus_mv);
                uart_send_string(buf);
            }

            if (threshold_alert) {
                threshold_alert = 0;
                uart_send_string(" [ALERT!]");
            }
            uart_send_string("\r\n");

            /* Re-arm the watchdog once the reading is back in the band */
            if (alert_active && pot_adc < AWD_HIGH_THRESHOLD - 100
                             && pot_adc > AWD_LOW_THRESHOLD + 100) {
                alert_active = 0;
                GPIOC->BSRR = (1 << 13);        /* LED off */
                ADC1->SR = ~ADC_SR_AWD;
                ADC1->CR1 |= ADC_CR1_AWDIE;
            }
        }

        __WFI();
    }
}
```

### Check it

- A multimeter on PA0 agrees with `POT` within about 1 percent. `VDDA` reads 3200 to 3400 mV (Vrefint is specified to about 3 percent).
- Above 2.4 V: one `[ALERT!]` line and the LED stays on. Below about 2.3 V the LED goes off, and the next crossing gives one new alert.
- The INA219 feeding a 100 ohm resistor from 3.3 V shows about 33 mA, and `I` equals `Vbus` / 100 within a few percent.
- The internal temperature sensor differs from chip to chip by up to about 0.09 V either way at 25 C (about 20 degrees). Trust its changes, not its value: a warm finger raises it within seconds.

Put the analog output of a vibration or current sensor on the watched channel and its limit is checked on every conversion with no processor work, which suits a motor or a pump.
